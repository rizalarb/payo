# PAYO - Landing Page

Marketing landing page untuk aplikasi PAYO (Point of Sales dengan On-Device AI).

## 🌐 Live Website

**URL:** https://rizalarb.github.io/payo/

## 📁 Files

- `index.html` - Halaman utama
- `styles.css` - Styling
- `script.js` - Interaktivitas

## 🔧 Cara Enable GitHub Pages

1. Buka repository di GitHub
2. Pergi ke **Settings** → **Pages**
3. Di bagian **Source**:
   - Pilih **Deploy from a branch**
   - Branch: `main`
   - Folder: `/docs`
4. Klik **Save**
5. Tunggu 2-5 menit, website akan aktif!

## 🔍 SEO

Landing page sudah dilengkapi dengan:
- Meta tags untuk SEO
- Open Graph tags untuk social sharing
- Responsive design untuk mobile

## 📝 Update Website

Untuk update website:
1. Edit file di folder `/docs`
2. Commit & push ke branch `main`
3. GitHub Pages akan auto-update dalam 2-5 menit
